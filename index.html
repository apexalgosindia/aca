How to open your account

The account is opened normally, then shifted to XTS a couple of days later. Don't log in during the wait — that's the part people get wrong.

1

Complete the application

Click the link below and finish the account-opening process. Start the AC Agarwal application →

2

Wait for your client ID

Your client ID arrives by email in 1–2 days once the account is opened.

3

Don't log in yet

Leave the account alone — no login, no activity. It needs to be shifted to XTS first. Wait another 1–2 days, and your market-data and interactive API details will arrive by email. You can then reset your password and log in to the API dashboard to view your API keys.

4

You're set

Account open, XTS active, API keys in hand — you can log in and start trading.

5

Use the ACA Math app and terminal

Since your account runs on XTS, always trade through the ACA Math app and terminal — not the Bloom app, which isn't built for XTS accounts.

NOT NEEDED HERE

Market Data

USE THIS ON TRADETRON

Interactive Order (Algo)

This is the one you connect to Tradetron. No static IP required. It must show Active status with an Algo Id attached to each exchange segment (NSECM, NSEFO, BSEFO).

ONLY IF YOU TRADE MCX

Interactive Order (Non-Algo)

You only need this one for MCX. It requires a static IP bought from Tradetron, set as the Primary IP here — covered in the MCX section below.

API MISSING, NO ALGO ID, OR NOT ACTIVE?

If your Interactive Order (Algo) API isn't showing up, has no Algo Id attached, or isn't Active — that's on AC Agarwal's side to fix. Email care@acagarwal.com directly with your client ID.

Connecting the API to Tradetron

Once your XTS API keys have arrived, wire them into Tradetron in a few minutes.

1

Open Broker & Exchanges

In Tradetron, go to the Broker and Exchanges page and click Add Broker.

2

Select the right broker entry

Choose AC Agarwal Retail XTS from the list.

3

Enter your Interactive API details

Use the details from the email you received, or copy them directly from the API dashboard.

4

Add app key and secret

Enter your app key and secret. Leave the token field blank, then save the broker.

5

Regenerate the token

Click the small refresh icon next to the pencil icon to trigger token generation.

6

Confirm it worked

Token generation should complete successfully. If it doesn't, message our support below — don't wait on hold elsewhere.

MCX needs a second broker connection on Tradetron and a static IP — see the dedicated MCX setup section below.

How to add the MCX broker

MCX runs through a second broker connection on Tradetron, tied to your Interactive Order (Non-Algo) API and a static IP.

1

Add the MCX broker

In Tradetron, go to Broker & Exchanges again, click Add Broker, and select AC Agarwal Retail XTS OLD.

2

Enter your Non-Algo API details

Use the app key and secret from the Interactive Order (Non-Algo) API in your XTS dashboard. Leave the token field blank and save.

3

Buy a static IP

A Buy Static IP button now appears next to this broker on Tradetron's brokers page. Buy it and copy the IP address.

4

Update the IP in XTS

In the XTS API dashboard, open the Interactive Order (Non-Algo) API, click Update IP, and paste the static IP into Primary IP. Save — then click Save IP again to confirm.

5

Regenerate the token

Back in Tradetron, regenerate the token for this broker, same as before.

6

Deploy your MCX strategies here

Deploy MCX strategies specifically under the AC Agarwal Retail XTS OLD broker — not the main one.
